用户代码是不可信输入。沙箱要假设它会尝试逃逸、耗尽资源、干扰宿主机。

## 三层分别挡什么

1. **libseccomp 白名单**：拦截 `fork` / `vfork` / `execve` / `listen` / `openat` 等高危调用，缩小可操作面。
2. **RLIMIT**：限制 CPU 时间、栈与堆，防止死循环和内存炸弹。
3. **容器配额**：外层 Docker 再卡 CPU / 内存，作为宿主机级兜底。

任何一层单独看都不完美，叠在一起才能把「恶意代码搞挂机器」的概率压下去。

## 和业务能力的关系

协同编辑、音视频面试可以并行建设，但判题链路的安全基线必须先于功能炫技。WebSocket 心跳与断线重连是体验问题；沙箱逃逸是事故问题。

做安全沙箱时，我更相信**默认拒绝 + 显式放行**，而不是默认放开再一项项堵。
