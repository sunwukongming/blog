title: TypeScript NoInfer：抑制多余推断
date: "2026-10-25"
category: frontend
summary: 泛型默认会从所有参数位推断。这篇写 NoInfer<T>：保住由别的参数决定的类型，避免默认值或回调把 T 拉宽。
---

部分 API 希望 **T 只由第一个参数决定**，后面的默认值或回调不要参与推断。TypeScript 的 **`NoInfer<T>`** 把该位置排除出推断候选。

## 例子

```ts
function createPool<T>(
  seed: T,
  fallback: NoInfer<T>,
): T {
  return seed ?? fallback;
}

createPool("a", "b");      // T = string
createPool("a", 1 as never); // 故意不匹配会报错
```

没有 `NoInfer` 时，`"a"` 与 `1` 可能把 `T` 推成 `string | number`。带上后，`T` 锁在 `seed`，`fallback` 必须兼容。

## 边界

- 需要 TS 5.4+（或等价 lib）。  
- 只影响推断，不改变运行时。  
- 与 `satisfies`、`const` 类型参数分工不同：前者校验，后者字面量收窄；`NoInfer` 管「从哪边推」。
