在 `<script setup lang="ts">` 里用**纯类型**声明 props 时，默认值不能写在类型里，需要 **`withDefaults`**：

```ts
const props = withDefaults(
  defineProps<{
    size?: "sm" | "md" | "lg";
    label?: string;
  }>(),
  {
    size: "md",
    label: "",
  },
);
```

## 边界

- 仅对**可选**属性给默认值；必填项放进类型且不要出现在 defaults 对象。  
- 对象/数组默认值不要共享可变引用——工厂函数形式按当前 Vue 文档来。  
- 与 **`defineModel`**、**`defineOptions`** 互补：一个管 v-model，一个管组件选项，本文只管 props 默认。  
- 运行时 `defineProps({ size: { default: "md" } })` 仍可用；类型版 + `withDefaults` 更贴 TS 工作流。
