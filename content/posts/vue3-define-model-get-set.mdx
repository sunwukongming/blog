`defineModel` 默认直接透传。需要「展示小写 / 对外大写」或「空串当 undefined」时，可用 **get / set**：

```ts
const title = defineModel<string>({
  get(value) {
    return value ?? "";
  },
  set(value) {
    return value.trim();
  },
});
```

模板里仍 `v-model="title"`；set 的返回值进入 `update:modelValue`。

## 边界

- `get`/`set` 是**可选**的；多数场景普通 `defineModel<string>()` 即可。  
- 与 **多个** `defineModel('foo')` 命名模型兼容；每个模型各自 get/set。  
- 别在 set 里做重 I/O；变换保持纯、可预测，副作用放 watch。  
- 和 **defineEmits** 手写 `update:xxx` 二选一：已用 defineModel 就不要重复 emit 同名更新。
