做会起伏的形体，最常见的思路是：**在顶点着色器里沿法线位移**。

## 从正弦波开始

最简单的海浪是几层不同频率的正弦叠加：

```glsl
float h = 0.35 * sin(p.x * 0.6 + uTime * 0.9)
        + 0.22 * cos(p.z * 0.8 - uTime * 0.7)
        + 0.12 * sin((p.x + p.z) * 1.3 + uTime * 1.4);
```

文章页背后的点阵就是这三行。

## 加入噪声

正弦波太规律，看久了会发现重复。换成 simplex noise 之后，形状就不再可预测了：

```glsl
float d = snoise(normal * 1.4 + uTime * 0.35) * 0.3;
vec3 p = position + normal * d;
```

## 颜色

用位移量 `d` 和菲涅尔项去查一个余弦调色板，就能得到虹彩的效果。这个技巧来自 Inigo Quilez 的文章。
